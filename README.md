# Trained

A tiny dark-mode phone app that tells Mark what he trained last, so he picks
something different today. Not a workout logger: no sets, reps, exercise
weights, plans, rest timer or weight tracking. One screen.

**Live app:** https://marktran4.github.io/trained/

## Put it on your phone

1. Open the link above in Safari.
2. Share button, then **Add to Home Screen**.
3. Open it from the home screen icon. It runs full-screen like a normal app.

## What it does

- **Category list** - one row per category (Chest/Shoulders/Legs/Cardio/Back by
  default), name on the left, a dotted leader, days since on the right. Stalest
  first; never-trained at the top. **Tap a row to log today in one tap**, with
  an Undo toast. The "..." on a row opens the backdate sheet (Today / the two
  previous weekdays / pick a day, plus an optional note).
- **One entry per day.** Logging onto a day that already has a different
  category asks "Change today from Chest to Legs?" first.
- **History** - last 8 weeks as a Monday-first calendar. Trained days are filled
  with the category colour plus its first letter. Header shows "N / 28 days".
  Tap any day to change its category, edit the note, remove it, or log onto it.
- **Undo** on every log, change, remove, note edit and restore (5 seconds).
- **Settings** (gear) - rename/add/delete categories (cap 8; deleting keeps
  history), pick a colour from 8 swatches, **Back up** (JSON file via the iOS
  share sheet to Files / iCloud Drive, or a download) and **Restore** (preview,
  confirm, replace; the previous data is stashed under `trained.v1.pre-restore`).
- A red banner appears if the browser refuses to save.

## Dev notes

- Files: `index.html` (markup), `styles.css`, `app.js` (DOM + state, ES module),
  `logic.js` (pure date/data functions, no DOM), `sw.js` (offline shell,
  cache-first), `manifest.webmanifest` + icons. No framework, no build step.
- Tests live outside the deploy folder: `../test/logic.test.js`, run from the
  repo root with `node --test` (needs Node 20+; `package.json` marks it ESM).
- All data lives in one `localStorage` key (`trained.v1`, `schemaVersion: 1`).
  Only optional fields get added (`category.color`). `weights` from the old
  weight tab is kept in storage and in backups but never shown. Other keys:
  `trained.v1.lastBackup`, `trained.v1.pre-restore`, `trained.v1.corrupt-backup`.
- All dates are local dates (never UTC). Legacy days with several sessions show
  the last one; days-since still counts all of them.
- Icons are generated by `../make_icons.py` (pure stdlib, no PIL).
- Source of truth lives in `~/side-projects/gym-tracker/`; the `trained` repo is
  just the GitHub Pages deploy target.
