How to run the test

Steps (about 10 minutes)
  1. In Safari, open this page and Share → Add to Home Screen. Name it Spike.
  2. Build the Shortcut from spike/README.md (sleep version), or the 2-action quick test first.
  3. Run the Shortcut. It copies the data and opens this page's address.
  4. Note where it opened: Safari (amber badge) or the Spike app (teal badge).
  5. Open the Spike icon on your home screen. Does the verdict say PASS?
  6. Either way, tap Paste from Shortcut in the Spike app. That's the fallback.
  7. Screenshot the Spike app's verdict and sleep table and send them to Claude.
